# Solidity-metrics-fix
A Windows only fix to be able to generate reports for solidity files, which always gave the error "no valid solidity source files found". ensure to uninstall the original extension first.
close visual studio as well, install by running code --install-extension "PATH\TO\FILE\solidity-metrics-windows-fix.vsix" (powershell)

If selecting a scope file, follow this format.
src/FileName.sol
script/*.sol
